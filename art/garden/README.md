# Rooftop garden art (Day 10+)
This art was generated by `python3 make_garden.py`. It uses the palette from appartement-411/js/art.js. There is no text in any image. Labels are drawn by code in Noto Sans, falling back to DejaVu Sans, and never in a pixel font.

## What's here
- **rooftop/**: `rooftop_day.png` and `rooftop_night.png`, each 192×256 (12×16 tiles of 16 px), plus ×4 versions.
  - The scene has a Paris skyline with the Eiffel Tower, domes and Haussmann roofs.
  - It has a stone parapet, a tiled deck, railings, a hatch door at the bottom and a string of lights.
  - The night version is baked in the D style, using the PR #8 light numbers (cool multiply plus warm light from the bulbs and the door).
- **props/**: `pot_dry_1..6`, `pot_empty`, `basil_planted`, `old_chair`, `wood_sign` (blank), `watering_can` and `weeds`. Each comes native plus ×4, and there's a `props_sheet`.
- **garden_parts/**: every part is drawn on one shared 18×52 canvas, which is 72×208 pt at ×4. The pivot is the centre of the pot's base, at (9,52).
  - Layer order: `pot_back` (includes the soil cutaway) → `roots_1..3` → stem → `leaves_<state>_<n>` → `pot_front`.
  - Use the matching stem for each state: `stem_n` with full leaves, `stem_wilting_n` with wilting leaves, and `stem_dormant_n` with dormant leaves.
  - The four heights are n = 1..4, and each leaves layer must use the same n as its stem.
  - Dormant is a bare brown stem with one tiny green bud, so the plant is resting, not dead.
  - `leaves_flash_n` is the yellow-leaf frame for a missed answer.
- **garden_screen/**: `garden_bg_390x844.png` (no UI and no text) and three composite demos: `demo_full`, `demo_mixed` and `demo_dormant`.
- **manifest.json**: lists every file, the props' anchors, the part rules, and the five slot anchors and safe areas at 390×844.
- **contact_sheet.png**: rooftop day, rooftop night and the mixed demo.
