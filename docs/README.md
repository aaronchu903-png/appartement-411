# Appartement 404 - Project Pack

Version 1.0 | 2026-10-08

One replacement for both previous Startup and Handoff documents. Use this package alone; the old files are superseded, not additional instructions.

## Files

| File | Owns |
|---|---|
| `FINAL_PROJECT.md` | The complete destination: the game the founder ultimately wants. |
| `CEO.md` | CEO mandate, working style, autonomy, budget and progression decisions. |
| `TEAM.md` | CTO, product/learning and visual-design responsibilities. |
| `STAGE_01.md` | The currently authorized build scope, first delivery and acceptance gates. |
| `CURRICULUM_WEEK_01.md` | The first seven learning episodes and their learning checks. |
| `STATE.md` | Actual implementation status, evidence, blockers and next action. |

Read in that order. Current scope may simplify the destination; it must not silently redefine it. Record new founder decisions in the document they change. Keep changing implementation facts in `STATE.md`, not in the vision.

Working documents use English. Communicate with the founder in Chinese. In-game dialogue is French, with progressively reduced Chinese support.

## Start

Give the package to the CEO Bot. If ZIP attachments cannot be read in that environment, extract and attach these Markdown files together.

Send:

```text
Read README.md and the six documents it identifies. Adopt CEO.md and
coordinate the responsibilities in TEAM.md. Preserve FINAL_PROJECT.md
as the destination. Start STAGE_01.md with A404-001, not the entire
future world. Inspect any existing project before creating or replacing
files. Use CURRICULUM_WEEK_01.md for learning content and update STATE.md
with actual results. Deliver a usable artifact and verification evidence,
not another general project plan. Use Chinese with me. Stay within the
budget and authorization boundaries in CEO.md.
```

This package contains specifications, not application code or evidence of a deployed product.
