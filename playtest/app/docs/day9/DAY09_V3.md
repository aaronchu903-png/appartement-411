## 1. Framing rules (portrait, every beat)
- Screen = **scene zone top ~55 %**, **panel zone bottom ~45 %** whenever a question/M2/M3/M4 panel is open. With a panel open, the camera re-frames so the **acting subject sits in the scene zone** (faces, hands, cat, object), with a floor/table line visible. **Never a ceiling-only frame**; no popup covers the action (FEEDBACK 5, 9).
- New words: **show, then say.** The action plays first (≥0.8 s), the line comes after, the word card is one tap away (Day 1 model: cat hides behind the sofa → « le chat / le canapé / derrière »).
- Shots: **W** wide (room/roof), **M** medium (waist up, 1–2 characters), **CU** close-up (hand, object, face, paw). Cut on action, not on text.
- **Vanish grammar (the thread’s visual rule):** each vanish = object in shot → a cutaway on someone talking → back: object gone, a tail tip leaves the frame edge (0.5 s). Never highlighted, never a hotspot. Attentive players get it; nobody says it until E.
