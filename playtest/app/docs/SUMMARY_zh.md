**目标**：Astra 在 `app/` 里从零独立做完整的 Day 8，包括进入画面、全部界面、动画、音频、花园复习和小猫小游戏，手机优先。基于它自己的花园原型，去掉网站感。旧游戏冻结不动，不公开上线。

**故事线顺序**：进入画面 → 早上用 Martin 的水壶复习盆①「Chez nous」→ 厨房早晨（住满一周、Regarde la plante）→ 小猫小游戏 → Boum 杯子掉了 → Lefèvre 送罗勒、约六点 → Noé 语音留言（听写 six heures）→ 室友群聊 3–4 条短信 → 17:55 下楼、喝汤、Croissant 占空椅子、星期四邀请（选择）、一个人住 → 交钥匙 → 第一次上天台、种罗勒、第一次浇水 → 结尾钩子。

**小猫小游戏**：Croissant 把花盆往桌边推，每推一下出一道复习题。答对就拦住它（反应越来越可爱），答错它就再推一点。花盆永远不会摔，到边上 Noé 会接住。必须用和花园同一套复习引擎和 FSRS 卡片，并写测试证明。

**花园**：5 种自动打分题型，答完一律播放正确语音。植物不实时长，每天第一次打开时结算隐藏照顾值，一个早上最多揭晓一个盆的变化。
