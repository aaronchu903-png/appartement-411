# 411 rooftop garden set (global style B)
Generated by `gen_rooftop.py` (original PIL code art; imports helpers L, C, steps, grade, put, COOL_T, WARM from ../kitchen/gen_kitchen.py without editing it). Palette `../../palette.json` (28 colours). Validate: `python3 check_manifest.py`, `python3 check_palette.py`.
Same format as the kitchen: `rooftop_{v}_sheet.png` atlases (not colour-graded; per variant only the scenery colours, string lights on/off change), `preview_{v}_x6.png`, `pieces/{v}/<file>.png`, `manifest.json` (+ `stage` block), `light/`, `stage_{v}_x1.png` / `_x6.png`, `composite_landscape_{v}.png`, `composite_{wide,medium,close}_{game,shorts}_{v}_1080x1920.png` + `_small`.
Slots, sizes, anchors, sit line: see `SLOTS_rooftop_NOTES.md`.

Design for reuse: sky / far skyline / tower / near skyline are separate tiling layers (parallax, seasons, rain overlays later), ungraded because they carry their own per-variant colours (like the kitchen window pane). Pots: pot 1 « Chez nous » has 3 growth stages; generic round/tall/trough pots have empty+planted states and documented recolour rows for future pots 2/3. Door has closed/open. Bench has a sit line + seat slots. No text or numerals anywhere.

Lighting (Soir rule): evening = warm multiply base + flat low-sun ellipse (multiply only). Night = kitchen teal cool base x1.25; string-light ADD: per bulb a flat floor pool 56/28 + a coping catch-light 30, no in-air glow; multiply lift 0.45 below each bulb on props/cast. Cast: multiply 0.25/0.6, add 0.6.
