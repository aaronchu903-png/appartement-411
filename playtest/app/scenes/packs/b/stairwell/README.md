# 411 stairwell / landing set (global style B)
Generated by `gen_stairwell.py` (original PIL code art; imports helpers L, C, steps, grade, put, COOL, COOL_T, WARM, CAP, BOT from ../kitchen/gen_kitchen.py without editing it; rooftop files untouched). Same format as kitchen/rooftop: `stairwell_{v}_sheet.png` atlases (ungraded), `preview_{v}_x6.png`, `pieces/{v}/<file>.png`, `manifest.json` (+ `stage` block), `light/`, `stage_{v}_x1.png` / `_x6.png`, `composite_landscape_{v}.png`, `composite_{wide,medium,close}_{game,shorts}_{v}_1080x1920.png` + `_small`.
Slots: `SLOTS_stairwell_NOTES.md`.

Design: a Parisian 4th-floor landing. Cream upper wall with dentil cornice, oak chair rail, panelled wainscot, terracotta tomette floor. Navy door = home (411), plum door = neighbour (recolourable). Front-view flight rising right off-stage with oak handrail on wrought-iron balusters and a brass-capped newel. Upper wall dressed by the landing window, bulb, notice board, wall lamp, horizontal + vertical pipe runs, so medium/close crops have no tall bare band.

**No text / numerals:** the door number 411 is only *suggested*: a small brass plate with three abstract dots (not digits), a brass lintel strip, a peephole and a tiny pink heart charm (same motif as pot ① « Chez nous ») + the warm striped doormat make it read as home. Notice-board papers and the parcel label are blank shapes.

Lighting (Soir rule): see SLOTS notes. Night: bulb pool on the landing, no in-air glow; a moonlit shaft from the window was tried and removed (read as a grey block).
